# בוחן תרגול — התנהגות צרכנים

אתר תרגול למבחן בקורס התנהגות צרכנים: שאלות אמריקאיות, סימולציית מבחן, דף עזר להדפסה ופודקאסט.
הכול נבנה מסיכומי המצגות של הקורס ומדף התרגול שחולק לקראת הבחינה. לתרגול לימודי בלבד.

## מה יש כאן

| קובץ | מה זה |
|---|---|
| `index.html` | הבוחן: מצב תרגול (משוב והסבר אחרי כל שאלה) וסימולציית מבחן (14 שאלות, ציון וסקירה בסוף). קובץ אחד, עובד גם בלי אינטרנט. |
| `sheet.html` | דף עזר להדפסה, שלושה עמודי A4. בבחינה מותר חומר עזר מודפס. |
| `podcast/` | תסריטים בשני קולות, ודף נגן עם קובצי MP3 (אחרי בנייה). |
| `src/` | המקור: בנק השאלות, התבנית, דף העזר וסקריפט הבנייה. |

בכל מצב אפשר לעבור בין השאלות ב«הקודמת» וב«הבאה», או בלחיצה על מפת השאלות. בתרגול המפה צבועה
(ירוק לנכונה, אדום לשגויה), ובסימולציה מסומנות השאלות שנענו. תשובה שניתנה נשמרת, יחד עם ההסבר שלה.

## הנושאים לבחינה

לפי דף התרגול: יחידה 2 (הכרה בצורך, ומודל הערכים ללקוחות פרטיים ועסקיים) · מצגת 3 (תפיסה: חשיפה, קשב,
פרשנות וגשטלט) · מצגת 4 (זיכרון: טווח קצר, טווח ארוך והרשת הסמנטית, חסימות, מרומז מול מפורש) ·
מצגת 5 (מעורבות: הגורמים למעורבות, ודפוסי הקנייה לפי עשהאל).

יחידה 1 («הצרכן החדש») אינה ברשימה: יש עליה כמה שאלות רקע, והיא כבויה כברירת מחדל.
החלק האחרון של מצגת 5 (מאמצי השיווק ברמות מעורבות שונות) מסומן בסיכום כהעשרה בלבד, ואין עליו שאלות.

## בנייה

```bash
cd src
python build.py
```

הסקריפט מרכיב את `index.html` מ-`template.html` ומקובצי `bank*.js`, כותב את `sheet.html` מ-`src/sheet.html`,
מעדכן את הטבלה שלמעלה, ומריץ בדיקות (נדרש node): מבנה השאלות, כפילויות, התאמה בין המפתח להסבר,
ו«תל האורך» (שהתשובה הנכונה לא תהיה באופן עקבי הארוכה או הקצרה ביותר).

סכמת שאלה:

```js
{l:3, t:"קשב", s:"יישום", q:"השאלה", o:["1","2","3","4","5"], c:1, e:"הסבר"}
```

`l` מספר היחידה, `c` האינדקס של התשובה הנכונה לפני הערבוב.

## פודקאסט

```bash
cd podcast
cp scripts/plain/*.txt scripts/     # רק אחרי שינוי בתסריט הלא מנוקד
python nikud.py                     # מנקד (Nakdan של דיקטה + nikud-overrides.txt)
python build.py                     # מסנתז (edge-tts) ובונה את דף הנגן
cd ../src && python build.py        # מוסיף לבוחן ולדף העזר את הקישור לפודקאסט
```

- `scripts/plain/` — התסריטים בלי ניקוד, המקור לעריכה. `scripts/` — אותם תסריטים מנוקדים, שמהם מסנתזים.
- שני קולות: `א:` המסביר (Avri), `ש:` המראיינת (Hila). `~4` הוא שקט של ארבע שניות לפני תשובה.
- `nikud-overrides.txt` — ניקוד ידני למונחי הקורס ולשמות, שגובר על המנקד האוטומטי.
- נדרשים: Python עם `edge-tts`, ו-`ffmpeg`.

**גיבוי כשהשירות של edge-tts לא עונה** (למשל שגיאת 403): `python build_local.py` בונה את אותם פרקים בקול
העברי שמותקן ב-Windows (Microsoft Asaf), בלי רשת. יש שם רק קול אחד, ולכן שורות המראיינת מוגבהות בגובה
הצליל, וההגייה פחות מדויקת. דף הנגן מציין שזו גרסה זמנית, עד ש-`python build.py` בונה מחדש את כל הפרקים.

הצינור (האתר, הבדיקות והפודקאסט) הועתק מהאתר `management-quiz`.
